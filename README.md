## Research

**Interpretable molecular solubility prediction** (final-year project, University of Leeds, advisor Prof. Yongquan Jiang) — a descriptor-fused GINE reaches 0.56 / 0.93 RMSE on ESOL (random / scaffold split), and a calibrated Gaussian-NLL head cuts ECE from 0.070 to 0.033.
